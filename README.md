## Утилита для создания профилей .config

**Алгоритм:** перебирает все файлы в выбранном профиле и на каждый создаёт/заменяет символическую ссылку в .config

⚠️ Перед использованием убедитесь, что перенесли содержимое важных заменяемых файлов хотя бы в один профиль или иное безопасное место

##
**Дерево файлов** <br>
```tree
.vconfig/
├── profile1/
│   ├── program1.conf
│   └── program2/
│       ├── colorsheme
│       └── binds
└── profile2/
    └── ...
```

##

**Использование** <br>
```usage
vconfig <dirname> (~/.vconfig/<dirname>)
vconfig -d <dir>
vconfig --dir <dir>
```
